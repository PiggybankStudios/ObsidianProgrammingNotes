# Modes
## Normal Mode (Default) - **\<Esc\>**
- [ ] `$`: Goto end of line
- [ ] `dd`: Delete current line
- [ ] `u`: Undo
- [ ] `o`: Make new line and switch to *Insert Mode*
- [ ] `p`: Paste (See `y`ank binding in *Visual Mode*)
- [ ] `Ctrl+W Ctrl+W`: Switch to other pane (see `split` in *Command Line Mode*)

## Command Line Mode - **\<:\>**
- [ ] `<number>`/`$`: Goto line `<number>` (`$`=end of file)
- [ ] `/<string>`: Search the file for `<string>` (Press `n` to cycle through all matches after search)
- [ ] `q{!}`: Close file (`!` allows exit even if modifications are present, also `ZQ`)
- [ ] `x{!}`: Save and close file (`!` skips confirmation?, also `wq`)
- [ ] `set number`: Show line numbers
- [ ] `split <filename>`: Split the editing window in half vertically and open `<filename>` in the lower other half
- [ ] `vsplit <filename>`: Same as `split` but horizontal split (2 columns) instead of vertical
- [ ] 
## Visual Mode - **\<v\>**
- [ ] `Left`/`Right`: Select text
- [ ] `y`: "Yank" the current line (basically Cut)
