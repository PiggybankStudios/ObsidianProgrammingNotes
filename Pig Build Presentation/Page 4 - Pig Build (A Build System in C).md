## Pros 
- [ ] Same language
- [ ] Only need a C/C++ compiler installed
- [ ] Turing Complete
- [ ] You *could* re-use code (dangerous)
- [ ] **You can use a debugger**

## Cons
- [ ] Need a shell script to "bootstrap"
- [ ] Duplication of code
- [ ] C/C++ error messages are not always helpful
- [ ] Compiling+Linking separate *.exe* every time you build (fixed by auto-recompile)
- [ ] Cross platform concerns (only dev platforms, not all targets)
- [ ] Turing Complete
